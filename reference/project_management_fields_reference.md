# Project Management Field Reference

This document provides two reference sets of fields:  
1. **Minimal Core Fields** — the essential fields used across almost all project management tools and industries.  
2. **Full Canonical Schema** — a comprehensive list of commonly used fields, grouped by category.  

---

## 1. Minimal Core Fields

| Group                   | Field                 |
|--------------------------|-----------------------|
| **Core Identification** | Title / Name          |
|                          | Summary / Description |
| **Tracking & Progress** | Status                |
|                          | Priority              |
| **Time & Scheduling**   | Start Date            |
|                          | Due Date / End Date   |
| **People & Ownership**  | Owner / Assignee      |
| **Business Context**    | Client / Stakeholder  |
| **Tracking & Progress** | Progress %            |

---

✅ Use the **Minimal Core Fields** for lightweight project/task tracking.
