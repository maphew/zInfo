TITLE: Pico.css Sass Customization Example
DESCRIPTION: This example shows how to customize Pico.css using Sass. It demonstrates enabling or disabling modules using the @use directive, allowing for a tailored build of the framework.

SOURCE: https://picocss.com/docs/v2

LANGUAGE: Sass
CODE:
```
@use "@picocss/pico/scss/pico" with (
  // Disable components
  $accordion: false,
  $card: false,
  $dropdown: false,
  $nav: false,
  $progress: false,
  $tooltip: false,

  // Enable components
  $button: true,
  $form: true,
  $grid: true,
  $input: true,
  $modal: true,
  $table: true,
  $typography: true,

  // Customization variables
  $primary: #007bff,
  $border-radius: 0.25rem
);

// Compile Pico.css
@include pico.css();
```
