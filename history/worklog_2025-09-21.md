### 🚀 **How to Use**

**Installation:**
```bash
# Install with GUI dependencies
uv sync

# Or install as editable package
uv tool install -e .
```

**Running the GUI:**
```bash
# Launch GUI application
zinfo-gui

# Launch with specific cache database
zinfo-gui /path/to/cache.db
```

**Available Commands:**
- `zinfo scan` - CLI scanning (existing)
- `zinfo query` - CLI querying (existing)  
- `zinfo-gui` - **NEW**: Launch GUI application
